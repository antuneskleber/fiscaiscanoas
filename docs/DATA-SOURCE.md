# Fonte de dados

Os dados públicos do site foram extraídos da lista operacional fornecida para as 66ª e 134ª Zonas Eleitorais de Canoas, em 3 de outubro de 2026.

Foram publicados somente nome do local, endereço, zona, página de referência e seções. Nomes e telefones de fiscais não foram incluídos na aplicação pública.
